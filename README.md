# Commerce Cloud Integrations Scoop bucket

Manifests of [Commerce Cloud Integrations](https://www.commercecloudintegrations.com) tools
for [Scoop](https://scoop.sh).

## epx

[epx](https://github.com/commerce-cloud-integrations/emporix-cli) is a command-line client for
the Emporix Commerce APIs. On Windows (x64 or arm64), in PowerShell:

```powershell
scoop bucket add commerce-cloud-integrations https://github.com/commerce-cloud-integrations/scoop-bucket
scoop install commerce-cloud-integrations/epx
```

Upgrade with `scoop update epx`.

The manifest is written by the release workflow of epx for every release; changes made here
by hand are overwritten. Report problems in the
[epx repository](https://github.com/commerce-cloud-integrations/emporix-cli/issues).
